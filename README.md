# E-Commerce-Analytics-
E-Commerce Analytics involves collecting, analyzing, and interpreting data from online business operations to drive smarter decisions. This project examines sales performance, customer behavior, profitability, and regional trends using industry-standard tools.

## Project Objective 
To leverage SQL, Excel, Power BI, and Tableau for analyzing e-commerce data, transforming raw datasets into interactive visualizations and meaningful business insights that help improve sales performance, customer retention, inventory management, and operational efficiency.

## Tools used 
Excel

Power BI

MySql

Tableau

## Question (KPI's)
Total Revenue 

Gross Merchandise Value

Monthly Revenue Growth

Cancellation Rate

Total Conversions,Impressions,Clicks

Average Order Value 

On-Time Delivery Rate

Average Shipping Days

Customer Lifetime Value

Customer Acquisition Cost
